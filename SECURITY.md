# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability
reporting (the "Report a vulnerability" button on this repository's Security tab).
Never report a vulnerability in a public issue, pull request or discussion.

A response window will be published before v1.0.

## Scope

The scope of this policy will be defined in `docs/guarantees.md` (not yet written).

## Supported versions

None released yet.
